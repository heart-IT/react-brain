## ⚡ Act on this

**Next.js patched two critical unauthenticated RCEs, not the one it announced.**
The [August security release](https://nextjs.org/blog/august-2026-security-release) landed
2026-08-25 — a day *early*, because a second critical turned up after the schedule was
published ([the update](https://nextjs.org/blog/nextjs-security-release-august-2026-update)).
CVE-2026-75604 hits Windows-hosted apps on Pages + App Router without Cache Components, and
has **no workaround**. GHSA-2xp9-vwfh-vxw4 is an AVIF path through libheif/sharp — and note
what the fix is: the patch **disables AVIF optimization**. A fix that removes a feature is a
fix you want to know about before your image pipeline changes shape under you. Patched in
16.3.3 / 15.5.24. → [meta-frameworks](https://heart-it.github.io/react-brain/entries/meta-frameworks/)

**fbtee 4.0 removes the Babel compiler entirely.**
[v4.0.0](https://github.com/nkzw-tech/fbtee/releases/tag/v4.0.0) drops the babel-plugin and
preset packages for a native Rust/Oxc CLI. If you are on the Babel path, **3.3.0 is the
terminus** — this is a migration, not an upgrade.
→ [i18n](https://heart-it.github.io/react-brain/entries/i18n/)

**react-native-callkeep is dormant.** Last npm publish 2024-11, and it sits on the
pre-Jetpack telecom API. Software Mansion's
[write-up of what to use instead](https://swmansion.com/blog/react-native-callkeep-alternative-2026/)
points at expo-callkit-telecom (0.4.0) or an SDK-bundled call UI. (The post is
vendor-authored — Fishjam is theirs — which is disclosed in the entry.)
→ [media](https://heart-it.github.io/react-brain/entries/media/)

**Two floor-raises worth checking before you bump.**
[victory-native 42.0](https://github.com/FormidableLabs/victory-native-xl/releases/tag/victory-native%4042.0.1)
now requires Skia 2.6 (PathBuilder) and Reanimated 3.19.1.
[react-native-screen-transitions 4.0](https://registry.npmjs.org/react-native-screen-transitions/latest)
requires React 19.2, Reanimated 4 and Worklets 0.8; the v3 line remains for anyone who
can't move yet. → [charts](https://heart-it.github.io/react-brain/entries/charts/) ·
[animation](https://heart-it.github.io/react-brain/entries/animation/)

## Moved

**Waku froze its 1.0 API.** [1.0 RC](https://waku.gg/blog/waku-v1-rc) shipped 2026-08-25.
The minimal-React-framework position is now a stable target rather than a moving one.
→ [meta-frameworks](https://heart-it.github.io/react-brain/entries/meta-frameworks/)

**Worklets 0.12 graduated to `latest`.**
[0.12.1](https://github.com/software-mansion/react-native-reanimated/releases/tag/worklets-0.12.1)
is no longer a `next` install, which retires a caveat that had been standing in the entry
for months. Its partner [Reanimated 4.6](https://github.com/software-mansion/react-native-reanimated/releases/tag/4.6.0)
covers RN 0.83–0.87 and adds native callbacks for CSS animations and transitions.
→ [animation](https://heart-it.github.io/react-brain/entries/animation/)

**EAS Observe hit GA, and the pricing model changed underneath it.**
[Observe](https://expo.dev/blog/introducing-observe) replaces the beta's 10k-MAU tier with
**per-event** pricing (100K events free / $19 / $199, 90-day retention). Needs SDK 55/56/57
and a new binary. Still not a crash reporter — don't retire Sentry for it.
→ [observability](https://heart-it.github.io/react-brain/entries/observability/)

**TanStack Query 5.102 adds `query()` and `infiniteQuery()`.**
[The PR](https://github.com/TanStack/query/pull/10658) supersedes `fetchQuery`/
`fetchInfiniteQuery` and deprecates `prefetchQuery`/`ensureQueryData`. Additive, and it
respects `select`/`skipToken` — but the deprecations are the part that ages your codebase.
→ [data](https://heart-it.github.io/react-brain/entries/data/)

**GTKX 1.5** ships [@gtkx/forms](https://gtkx.dev/blog/gtkx-1-5) (React Hook Form against
Adwaita, typed) and @gtkx/i18n (gettext behind the react-i18next API). No breaking changes.
→ [desktop](https://heart-it.github.io/react-brain/entries/desktop/)

## New on the board

**React has a `browser()` API in canary.**
[`use(browser())`](https://react.dev/reference/react-dom/browser) marks a Client Component
browser-only: during SSR it suspends to the Suspense fallback. That is the principled
replacement for the `typeof window` and mounted-state hacks everyone has been writing.
Canary-only — this is a watch item, not a dependency.
→ [react-core](https://heart-it.github.io/react-brain/entries/react-core/)

**react-native-filament** fills a real hole: a
[PBR renderer as declarative components](https://margelo.github.io/react-native-filament/)
(Metal / OpenGL-Vulkan, ~4MB) sitting between react-three-fiber and a full engine like
Godot. Caveat stated plainly: quiet since May — 1.11.0, no publish or push in about three
months. → [games](https://heart-it.github.io/react-brain/entries/games/)

**Expo now ships its own agent layer.** [docs.expo.dev/agents](https://docs.expo.dev/agents/)
covers an official `expo` plugin for Claude Code and Codex, an MCP server with live docs
plus EAS Build history, Update channels and TestFlight metadata, and an AGENTS.md generated
by `create-expo-app`. Notably, Expo's own guide hands device control to the same tools this
entry already picked. → [ai-devtools](https://heart-it.github.io/react-brain/entries/ai-devtools/)

## Worth reading

**[Making React Testing Library tests 43% faster](https://sigh.dev/posts/making-react-testing-library-faster/)**
— the headline is RTL, but the whole win landed **upstream in jsdom** (label index, selector
fast path, event dispatch). The durable lesson: slow RTL is usually a jsdom-version problem.
→ [testing](https://heart-it.github.io/react-brain/entries/testing/)

**[How to find a Next.js memory leak in production](https://xabierlameiro.com/blog/nextjs/nextjs-memory-leak-in-production)**
— heap-signature correlation and retainer-chain reading, applied to three real framework
leaks across Next 15.5–16.2 (fixed in 16.3.0). A method, not a war story.
→ [observability](https://heart-it.github.io/react-brain/entries/observability/)

**[Speeding up Expensify's networking with NitroFetch](https://margelo.com/blog/speeding-up-expensifys-networking-with-nitro-fetch)**
— a production rollout with numbers: 15–30% faster requests, P50 startup −267ms on iOS and
−650ms on Android via prefetch-before-JS with account-scoped keys. Watch the Cronet
cert-pinning caveat. Vendor-written; the numbers are Expensify's.
→ [networking](https://heart-it.github.io/react-brain/entries/networking/)

**[Avoiding Server Component waterfall fetching with React 19 `cache()`](https://aurorascharff.no/posts/avoiding-server-component-waterfall-fetching-with-react-19-cache/)**

→ [react-core](https://heart-it.github.io/react-brain/entries/react-core/)

**[The tools started shipping their own instructions](https://saschb2b.com/blog/react-agentic-engineering-2026)**
— a survey of the MCP / AGENTS.md convergence across Next.js, MUI, Storybook and Playwright.
→ [ai-devtools](https://heart-it.github.io/react-brain/entries/ai-devtools/)

**[Working with the React Native Super App Showcase](https://www.callstack.com/blog/working-with-the-react-native-super-app-showcase-repository)**

## Didn't keep — and why

The corpus rejects more than it keeps. These are the rejections worth arguing about:

- **[PDFium vs PDF.js: choosing a React PDF engine](https://medium.com/@9haroon_dev/pdfium-vs-pdf-js-choosing-a-react-pdf-engine-2026-2c05c0ed55e7)**
  — genuinely good, bias-disclosed, and it covers a facet nothing in the corpus owns. Not
  kept because the URL fails WebFetch (403), browser-UA curl (Cloudflare) *and* Wayback (no
  snapshot; Save Page Now returned 520). A third-party text extractor can't stand as a
  receipt. **Reopens** on a snapshot, a republish, or PDF recurring — which would also
  justify opening the gap.
- **[Ionic Framework 9](https://ionic.io/blog/announcing-ionic-framework-9)** — off-scope.
  The corpus tracks Capacitor as a shell, not Ionic's UI layer.
- **[Making referential stability a type](https://www.jovidecroock.com/blog/referential-stability-types/)**
  — a Preact core author's `Stable<T>` phantom-brand experiment, and explicitly labelled as
  playing with an idea. Too early. **Reopens** on a shipped package or a lint rule.
- **[Rifm 1.0](https://trysound.github.io/rifm/)** — input masking at 1.0. One milestone
  isn't demand, and no entry holds a masking facet yet.
- **[react-native-streamdown](https://github.com/software-mansion-labs/react-native-streamdown)**
  — 0.2.0, still in swmansion-*labs*, and the same job is already held by
  react-native-enriched-markdown 1.0. **Reopens** at 1.0 or on promotion out of labs.

## Under the hood

The `cache()` post was originally skipped as a how-to. The advocate pass — a mandatory
re-read of every skip as a hostile reviewer arguing items back in — flipped it, because
neither react-core nor data held **any** `cache()` coverage. That is the measured failure
mode (this triage is keep-averse, 56/100 on the bench) being caught by the pass built to
catch it.

One dedupe miss this week: a stale-ShadowNodes article was kept into observability before
anyone noticed native already held it. The lint's shared-reading-URL warning caught it and
the duplicate came out.

The Next.js advisory only surfaced because of a **tripwire** — a standing caveat wired as a
release condition ("next ≥ 16.3.3 → capture the advisory"). The automatic patch-skip rule
would have swallowed 16.3.4 in silence. Both mechanisms working, one covering the other's
blind spot.
